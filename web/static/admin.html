Limits

Dreams tidy each character's memory during its quiet hours. Their model calls are not counted against any user's requests or tokens, so this cap is the only limit on them. Set it to what you are willing to spend per day.

Both are on by default. Turning one off stops it being read, refreshed and shown to users.

Posted as JSON when a user's daily, weekly or monthly token budget reaches 80% and again at 100%. Leave empty to turn it off.

Tiers

Each tier's monthly token cap, its daily and weekly limits (percent of the monthly cap; defaults 10% and 20%), the providers it may use, and models it may not use. Admins have no tier and no cap. A limit set on a user row overrides the tier's figure.

Backups

Each backup is encrypted with the backup password. The first admin sets it once, and every backup needs it, along with your two-factor code. Someone who downloads a backup can't open it without that password. A data backup holds the data, characters and settings, including .env. A full backup also holds the server code, so restore_backup.py can rebuild the whole install.

Model providers

Keys are stored on the server only and are never shown in full. Leave a key box blank to keep the saved key.
