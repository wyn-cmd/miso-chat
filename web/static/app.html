Pick a .txt, .md, .docx, .pdf or a screenshot that describes the character. Text is read directly, and pictures and scanned pages go through OCR. The draft fills this form for you to check before you create the character. Pictures are never used as the profile or background image.

Mind Palace (database searching)

Each entry joins the prompt when its keys appear in the recent chat. Keys match whole words, ignoring case and accents. Plurals and common endings (cat, cats, loved, stopping, cities) match on their own. For an irregular form, write both in one key, such as mouse|mice. Secondary keys narrow it further (see Logic). Always on entries join every reply.

Memory retention

The memories this character wrote for itself are scored by how useful they proved. Carrying on, agreeing or thanking it earns them a little; correcting it costs them. A weak memory fades faster and is eventually dropped. Anything you wrote yourself is never scored or dropped.

Affinity

Energy falls over a long conversation and recovers in silence. Affinity grows with each exchange and fades after several days apart. A lonely character may send you a check-in.

Admins can set these values by hand. The emotion follows the numbers unless one is picked here, and the simulation carries on from there.

Open a character or group chat to pin facts for it.

Pinned facts go at the end of the system prompt on every reply, so the character never forgets them. Keep them short.

Open a character to set its check-in.

Off by default. When it is on, the character sends you one message a day, asking how you are and picking up from the chat. The message is marked as a check-in, and a red dot on the character shows how many you have missed until you open the chat. If the server is not running at the chosen time, that day's check-in is skipped.

When

Open a character to set its dreams.

In its quiet hours the character reviews its recent memories, links facts that belong together, and drops automatic Mind Palace entries that repeat or contradict others. Pinned facts and your own palace entries are never changed. Dreams do not count toward your token budget.

Dreams are switched off on this server, so nothing runs until an admin turns them on.

Open a character to see your relationship.

Affection and trust grow when you are kind, share time together and ask about the character. Insults and deceit lower them. If you go a long while without spending time together, trust eases a little.

Relationships are switched off on this server, so nothing changes until an admin turns them on.

Your own entries for this character or group. A character's starting palace was copied to your account the first time you chatted with it. Changes apply from your next message.

Automatic entries

Each check suggests up to three entries and keeps the one whose keys come up most in the last 30 messages. When the limit is reached, the character chooses an automatic entry to replace. It can also correct an automatic entry when the chat changes it. Your own entries are never changed. Automatic entries are marked, and you can edit or remove them like any other.
