Miso Chat 1.4.0-beta-3 update

This beta-3 brings the server to 1.4.0-beta-3. It adds budget alerts (an amber warning at 80% of a daily, weekly or monthly token window, a red one at 100%, and an optional webhook set on the admin Limits page), chat export as EPUB and PDF, a Pinned facts card in Settings, scheduled check-ins for each character (off by default, sent at a set time or at a random time in a range, with a red count for missed ones), and backgrounds for group chats. It also fixes the terminal prompt flickering while typing, and adds more space between messages in the terminal client.

This is a beta. The terminal client is now 1.4.0-beta-3, and the server only accepts clients with the same major.minor version (1.4). Clients from 1.4.0-beta-2 are still accepted, but they do not have the message spacing or the larger picture. Download the 1.4.0-beta-3 client from the web app. Your existing chats and characters are not changed by the update.

1. Stop the web app.

2. Back up before you update. Make an encrypted backup from the admin page, or copy data/ and your character folders by hand. This zip does not contain them.

3. Extract this zip into the existing project folder, overwriting the files. Do not extract into a new folder.

   The zip leaves alone: .env, data/, every character folder, and the files you keep beside them.

4. No packages changed. You do not need to install anything. EPUB needs nothing extra, and PDF uses PyMuPDF, which is already in requirements.txt.

5. Data changes are automatic on start:

   - A new table stores each character's check-in schedule and its missed count. It is created empty on the first start. Nothing is scheduled until someone turns a check-in on.

   - Nothing else in data/ is changed.

6. Optional: to receive budget alerts by webhook, open the admin page, Limits, and enter the address under Budget alert webhook. Leave it empty to turn it off.

7. The terminal client needs the 1.4.0-beta-3 file. Download it from the web app.

8. Optional: install chafa to draw character pictures in the terminal client. The README has the steps.
