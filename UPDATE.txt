Miso Chat 1.6.0-beta-4 update

This beta brings the server to 1.6.0-beta-4 from 1.6.0. It adds prepaid credits in MCC, a balance page, an audit log, a password rule and upload scanning, and fixes a rate-limit block that could stop sign-in. The server adds two tables (audit_log and credit_requests), one column (users.credit_tokens) and one setting (credits_auto_accept) on first start. Chats, characters, accounts and the existing settings carry over.

Prepaid credits: each account has a token balance. When a tier's daily, weekly or monthly request quota is used up, the next request draws one credit instead of stopping, until the balance is empty. Open Balance from Settings to see the tier and balance. A top-up is a request with a token count and a price in MCC. An admin approves or rejects it on the same page, or turns on automatic approval so a request is credited at once. No payment processor is wired in; MCC is settled between you and the account holder.

Audit log: sign-ins, locks, admin actions and credit changes are written to a hash-chained table, so a gap or a rewritten row is visible.

Upload scanning: if ClamAV is installed on the server, a portrait, background, music track or imported zip is scanned before it is stored. Without ClamAV the check is skipped.

The terminal client is 1.6.0-beta-4. A 1.6.x client and a 1.6.x server work together because the major.minor matches, but the client file in this zip is the matching one.

Before you update, note these changes:
- New passwords need at least 12 characters and include a letter and a digit. Existing passwords keep working.
- State-changing requests must come from the same origin. A reverse proxy that rewrites the Host header may need its forwarded headers kept intact.
- The request rate limit is 30 a second or 600 a minute. Icon and background requests are exempt, and a burst gets a short cooldown rather than a permanent block.
- Character icons and backgrounds now cache for five minutes in the browser instead of being fetched on every page load.
- This beta zip carries no tests folder. Any tests already on the server are left in place and are not updated.

1. Stop the web app.

2. Back up before you update. Make an encrypted backup from the admin page, or copy data/ and your character folders by hand. This zip does not contain them.

3. Extract this zip into the existing project folder, overwriting the files. Do not extract into a new folder.

   The zip leaves alone: .env, data/, every character folder, and the files you keep beside them.

4. Data: the two tables, the column and the setting are created on first start. Nothing else in data/ is rewritten. Set credit prices and automatic approval from the admin page.

5. Start the web app again and sign in. Open Settings, then Balance, and send a test top-up; approve it from an admin account, or turn on automatic approval first. Open a character and check that the profile picture loads and stays cached on a second visit.

6. Run the terminal client from this zip. If an old client is still installed, replace it with client/miso_remote.py.

7. Report anything that breaks against the 1.6.0-beta-4 notes in CHANGELOG.md.
