Miso Chat 1.6.1 update

This release brings the server to 1.6.1 from 1.6.0. It adds prepaid credits with a balance page and admin top-up review, a hands-free voice call mode, Plexiglass in place of the Dusk look, and mini-games: a dice button beside the settings button opens a picker of small games to play with the open character, with three games built in, per-character progress, play limits, mood and relationship rewards and one narrator line in the chat, and an admin section that switches games on and imports new ones. A novel and a group chat can now have a background picture and up to three theme tracks of their own, and group chats keep theme music the way characters do; both are set on the novel's or group's edit page. The release also ships the desktop package for Windows, macOS and Linux as separate downloads from the release page: one installer for Windows (NSIS or MSI), a zip for macOS and an AppImage for Linux, with the packaged app checking for newer stable releases in the background.

The server adds two tables, one column and one setting on first start, so chats, characters, accounts and settings carry over.

The terminal client is 1.6.1. A 1.6.x client and a 1.6.x server work together because the major.minor matches, but the client file in this zip is the matching one.

Before you update, note these changes:
- Prepaid credits are off until an admin uses them. A tier's quota still applies first; credits are drawn only after it is used up.
- Mini-games are off until an admin turns them on under Admin, Mini-games, and switches individual games on. A game asks the character for a short line, so it uses the same request and token limits as a chat turn.
- A novel's background and theme music are kept in that novel's own folder, and a group's in the group's folder. Theme music needs ffmpeg on the server, like a character's track does.
- Calls need a working speech server under Admin, Model providers, Speech, with ffmpeg installed on the server. With speech off, the Call button stays hidden.
- Calls only work for solo characters, not groups or novels.
- The browser needs microphone permission. Use headphones so the microphone does not pick up the reply.
- The Dusk look is replaced by Plexiglass. A saved Dusk choice moves over. The old web/static/dusk.css is no longer used and can be deleted after the update.
- A new password needs at least 12 characters, with a letter and a digit.
- State-changing requests must come from the same origin. A reverse proxy that rewrites the Host header may need its forwarded headers kept intact.

1. Stop the web app.

2. Back up before you update. Make an encrypted backup from the admin page, or copy data/ and your character folders by hand. This zip does not contain them.

3. Extract this zip into the existing project folder, overwriting the files. Do not extract into a new folder.

   The zip leaves alone: .env, data/, every character folder, and the files you keep beside them.

4. Data: the server adds two tables, one column and one setting on first start. Existing chats, characters, accounts and settings are kept.

5. Start the web app again and sign in. Open Admin, Mini-games, switch the feature on and tick the games you want. Open a character's chat and press the dice button beside settings.

6. To use the desktop app, download the package for your system from the release page instead of this zip. The first start asks for a Gemini key by writing a .env in the app's own data folder and naming it.

7. Run the terminal client from this zip. If an old client is still installed, replace it with client/miso_remote.py.

8. Report anything that breaks against the 1.6.1 notes in CHANGELOG.md.
