Miso Chat 1.4.1 update

This update brings the server to 1.4.1 from 1.4.0. It adds mood and relationship state with bars, an event memory graph, group Mind Palace entries and group auto-reply, example messages on the character card, deleting messages from a chat, and two opt-in ways to spend fewer tokens: near-lossless quenching of older history, and effectiveness-weighted memory retention. The history window also now starts on multiples of eight messages so the prompt cache can be reused.

Every new switch starts off, and off means the old behaviour, so an install that changes nothing behaves as 1.4.0 did. Mood, relationship, the event graph and learned memory retention are admin switches on the admin page. Quenching is a per-account preference in Settings, Account. Group auto-reply is always on for group chats and has no switch.

This is a release. The terminal client is now 1.4.1. The server accepts clients with the same major.minor version, so a 1.4.0 client keeps working; 1.3.x clients are still refused. Your existing chats and characters are not changed by the update.

1. Stop the web app.

2. Back up before you update. Make an encrypted backup from the admin page, or copy data/ and your character folders by hand. This zip does not contain them.

3. Extract this zip into the existing project folder, overwriting the files. Do not extract into a new folder.

   The zip leaves alone: .env, data/, every character folder, and the files you keep beside them.

4. No new packages are needed if you are already on 1.4.0. If you are coming from 1.3.x or have not installed since, run:

       pip install -r requirements.txt

5. Data changes are automatic on start:

   - Two new tables are created empty: moods, holding energy, affinity and the emotion per character, and attitudes, holding affection and trust per character and account.

   - Memory retention keeps its scores in a small file in each character folder, created when the switch is first used, and removes rows for memories that are no longer stored.

   - Nothing else in data/ is changed.

6. Optional, from the admin page:
   - Mood and Relationship: switch each on for the server. Off is the default.
   - Event memory graph: switch it on only with dreaming on, because the nightly dream is what writes it.
   - Learned memory retention: switch it on to let self-written memories decay by outcome. Entries you wrote yourself are never scored or dropped.

7. Optional, per account, from Settings, Account: turn on Quench history. The context marker then reports how many characters the pass saved. It is near-lossless, not lossless: the newest messages, your own messages and every sentence with a figure, a name or a quotation are kept whole, and the pass stops while at least 92 percent of the window's distinct words survive. A quenched account may show a lower cached share on the stats page, because the older text changes slightly from turn to turn.

8. The terminal client needs the 1.4.1 file, or a 1.4.0 one. Download it from the web app, or from the release page on GitHub. Its SHA-256 is in the release notes.

9. Optional: install chafa to draw character pictures in the terminal client. The README has the steps.
