Miso Chat 1.5.2 update

This update brings the server to 1.5.2 from 1.5.1. It adds read-aloud for character replies, a Voice & audio settings panel, one Story & memory card for Worlds, Mind Palace and Dreams, a 0.95 default creativity for chats and groups, peak and off-peak pricing for the DeepSeek cost estimate, and fixes for command notices. The endpoints and the data layout are the same as 1.5.1, so chats, characters, accounts and the settings carry over.

Read aloud uses the voices installed in the browser or operating system. The server sends no audio. Nothing needs a new package, and requirements.txt is unchanged. ffmpeg and ffprobe are still needed only for video backgrounds.

The terminal client is 1.5.2. Its code is the same as 1.5.1 apart from the version string, and the server accepts any client with the same major.minor version.

Before you update, note these changes:
- The default creativity is now 0.95 for one-to-one chats and groups. A creativity you saved for a character or group still applies.
- Worlds, Mind Palace and Dreams are now under Settings, Story & memory.
- The engine initialises the event memory switch again; a comment had swallowed the line that set it.
- A tests folder ships with automated tests for the core logic and the sanitisation scans; run them with python -m unittest discover -s tests.
- The DeepSeek cost estimate now follows peak and off-peak hours. The server adds three columns to two usage tables on first start; earlier DeepSeek days are priced at the off-peak rate.

1. Stop the web app.

2. Back up before you update. Make an encrypted backup from the admin page, or copy data/ and your character folders by hand. This zip does not contain them.

3. Extract this zip into the existing project folder, overwriting the files. Do not extract into a new folder.

   The zip leaves alone: .env, data/, every character folder, and the files you keep beside them.

4. Data: the server adds three columns to two usage tables on first start, which needs no manual step. Nothing else in data/ is rewritten.

5. Start the web app again and sign in. Check the home page, a chat, Settings, Story & memory, and Settings, Voice & audio.

6. Open a chat with a character reply and press the speaker button. If no voice plays, check that the browser has voices installed under its speech settings.

7. Report anything that breaks against the 1.5.2 release notes in CHANGELOG.md.
