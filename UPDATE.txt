Miso Chat 1.5.1 update

This update brings the server to 1.5.1 from 1.5.0. It adds a fourth look (Dusk), a panda app icon, video and animated pictures for accounts and characters, and background circles for characters without pictures. It removes the Spore look. The endpoints and the data layout are the same as 1.5.0, so chats, characters, accounts and the settings carry over.

Video backgrounds need ffmpeg and ffprobe on the server's PATH. They are optional: without them, the rest of the app works, and a video upload is refused with a message. Install them before you use video. Nothing else needs a new package. requirements.txt is unchanged.

The terminal client is 1.5.1. Its code is the same as 1.5.0, and the server accepts any client with the same major.minor version.

Before you update, note these changes:
- Spore is gone. A browser that had chosen Spore now shows Moonlit.
- Pictures and videos saved before this update are not re-processed. They show without the new colour look and blur until you upload them again.

1. Stop the web app.

2. Back up before you update. Make an encrypted backup from the admin page, or copy data/ and your character folders by hand. This zip does not contain them.

3. Extract this zip into the existing project folder, overwriting the files. Do not extract into a new folder.

   The zip leaves alone: .env, data/, every character folder, and the files you keep beside them.

4. Data: no migration step is needed. Nothing in data/ is rewritten.

5. Start the web app again and sign in. Check the home page, a chat, and the Dusk look under Settings, Appearance, Theme.

6. Video: upload a short MP4 as a background and check it plays. If it is refused, check that ffmpeg and ffprobe run from a terminal on the server. On some phones a video shows only its poster frame; this is a known issue in CHANGELOG.md.

7. Report anything that breaks against the 1.5.1 release notes in CHANGELOG.md.
