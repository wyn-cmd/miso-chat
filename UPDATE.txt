Miso Chat 1.7.1 update

This release brings the server to 1.7.1 from 1.7.0, keeping the DeepSeek prompt stable across the turns that used to break it. It changes no settings and needs no new key.

New in 1.7.1:
- Regenerate, /redo and /regenerate re-send the turn's own prompt, so the provider reuses its cache for the whole prompt and only the new reply is billed. Before, the redo rebuilt the Mind Palace and the memory policy, which changed the system text and lost the cache for the entire history.
- A DeepSeek chat no longer sends the energy and affinity bands in the mood block. The band words sat in the cached system prompt, so each crossing rewrote it and the whole history behind it was billed at the cache-miss rate. In a 100-message simulation this takes the hit share from 88.5% to 93.0% and the peak-rate bill down by about 19%. The emotion and its tone still reach the model, and the settings page still shows both bands.
- The Mind Palace's constant entries can no longer be pushed out by the entry budget, which used to rewrite the system prompt on some turns.
- Open tensions now sit at the end of the system prompt, after the running summary and the author's note, so a tension change costs only what follows it.

The server adds no tables and no columns. Existing chats, characters, accounts and settings are kept.

The terminal client is 1.7.1. A 1.x client and a 1.x server work together because the major.minor matches, but the client file in this zip is the matching one.

If you are coming from 1.6.x or earlier, read the 1.7.0 notes in CHANGELOG.md first; they still apply.

Before you update, note these changes:
- A DeepSeek chat's mood block is shorter than the one every other model gets. The energy and affinity bands are no longer sent to a DeepSeek model, so the same character reads slightly less mood detail there.
- A tension change that arrives on its own, from resolving one in the chat page or from a save whose model wrote no summary, still costs the history behind it.
- A memory save on a DeepSeek chat sends the chat's own history. It reuses the prompt cache, so it is much cheaper than in 1.6.x, but it is still the largest single call a DeepSeek chat makes.
- A switch between two DeepSeek models costs one request on the model you are leaving, because the save runs there. A switch into DeepSeek keeps the compact save on the Gemini chain.
- The rolling window length setting is hidden for a chat on a DeepSeek model. The value you set stays saved and applies again when you switch back to another model.
- A solo DeepSeek chat's memory saves every 30 turns, not every 10, and each refresh reads the last 60 messages. Memory updates therefore arrive less often on those chats.
- The DeepSeek daily caps and the 120-a-minute budget are separate from the Gemini ones. An admin's per-account daily cap applies to each provider separately.
- A DeepSeek chat's memory save, dreams and the other background work run on the Gemini chain and count against the Gemini per-user caps. A DeepSeek account whose Gemini cap is used up has its background work stopped until the cap resets.
- OpenRouter models are free but have low request limits, and OpenRouter may log prompts. Do not use them for characters you want kept private.
- The desktop app is not rebuilt by this zip. Download its installer from the release page.
- Prepaid credits are off until an admin uses them. A tier's quota still applies first; credits are drawn only after it is used up.
- Mini-games are off until an admin turns them on under Admin, Mini-games, and switches individual games on. A game asks the character for a short line, so it uses the same request and token limits as a chat turn.
- A novel's background and theme music are kept in that novel's own folder, and a group's in the group's folder. Theme music needs ffmpeg on the server, like a character's track does.
- Calls need a working speech server under Admin, Model providers, Speech, with ffmpeg installed on the server. With speech off, the Call button stays hidden.
- Calls only work for solo characters, not groups or novels.
- The browser needs microphone permission. Use headphones so the microphone does not pick up the reply.
- A new password needs at least 12 characters, with a letter and a digit.
- State-changing requests must come from the same origin. A reverse proxy that rewrites the Host header may need its forwarded headers kept intact.

1. Stop the web app.

2. Back up before you update. Make an encrypted backup from the admin page, or copy data/ and your character folders by hand. This zip does not contain them.

3. Extract this zip into the existing project folder, overwriting the files. Do not extract into a new folder.

   The zip leaves alone: .env, data/, every character folder, and the files you keep beside them.

4. Data: the server adds no tables and no columns. Existing chats, characters, accounts and settings are kept.

5. Start the web app again and sign in. Nothing needs setting up for this release. A chat on a DeepSeek model picks up the shorter mood block and the steadier prompt on its next message.

6. To use the desktop app, download the package for your system from the release page instead of this zip. The first start asks for a Gemini key by writing a .env in the app's own data folder and naming it.

7. Run the terminal client from this zip. If an old client is still installed, replace it with client/miso_remote.py.

8. Report anything that breaks against the 1.7.1 notes in CHANGELOG.md.
