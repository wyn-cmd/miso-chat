Miso Chat 1.4.0 update

This update brings the server to 1.4.0 from 1.3.1. It brings together the 1.4.0 betas and the features added since. The main additions are: memory that is updated by changes, so a refresh cannot silently drop facts; episodic memory, which brings back earlier moments of a chat; automatic Mind Palace entries that a character can add itself; autonomous dreaming in quiet hours; scheduled check-ins; budget alerts; EPUB and PDF export; importing SillyTavern-style character cards; and group chat pictures and backgrounds. Plural and suffix matching for Mind Palace keys is also new.

The new features are switched off, or leave the existing behaviour as it was, until someone turns them on. Episodic memory and the memory bank are on by default. Automatic palace entries, check-ins, dreams and the webhook are off. Dreams are switched off on the server until an admin turns them on.

This is a release. The terminal client is now 1.4.0, and the server only accepts clients with the same major.minor version (1.4). Terminal clients from 1.3.x will be refused until you download the 1.4.0 client from the web app. Your existing chats and characters are not changed by the update.

1. Stop the web app.

2. Back up before you update. Make an encrypted backup from the admin page, or copy data/ and your character folders by hand. This zip does not contain them.

3. Extract this zip into the existing project folder, overwriting the files. Do not extract into a new folder.

   The zip leaves alone: .env, data/, every character folder, and the files you keep beside them.

4. Install the packages in requirements.txt again, so that PyMuPDF (used for PDF export) is present:

       pip install -r requirements.txt

5. Data changes are automatic on start:

   - Existing non-admin accounts are set to the lite tier, if they had no tier. Admin accounts have no tier and no token cap. Lite is 10M tokens a month, standard 20M, pro 100M and free 1M. A monthly budget set by hand for an account still wins over its tier.

   - New tables are created empty: favourites, character message counts, personas, check-in schedules and dream schedules. Character message counts are rebuilt once from saved chat history on the first start. On a large server this can take a little time.

   - Nothing else in data/ is changed. Episodes, palace state and dream records are created per character when they are first used.

6. Optional, from the admin page:
   - Autonomous dreaming: switch it on, then set how many days apart dreams run and the daily cap on dream model calls.
   - Budget alert webhook: enter the address under Budget alert webhook on the Limits page. Leave it empty to turn it off.

7. The terminal client needs the 1.4.0 file. Download it from the web app, or from the release page on GitHub. Its SHA-256 is in the release notes.

8. Optional: install chafa to draw character pictures in the terminal client. The README has the steps.
