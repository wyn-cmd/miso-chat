Miso Chat 1.6.0 update

This update brings the server to 1.6.0 from 1.5.2. It carries everything in the 1.6.0 betas (off-screen life, author's notes, a dream bubble viewer, reasoning levels per tier, a relationship speed set by the character creator, larger animated backgrounds, per-character check-in and dream frequency, and a settings tidy-up), plus the Story Bible and document import, a character wizard, Mind Palace checks, core memory, theme music and the Lantern look. The server creates no new tables on first start, so chats, characters, accounts and settings carry over.

The Story Bible is a wiki page of a chat: an overview, the characters met, places visited, items acquired, open questions and key events. It opens by clicking the character's icon or name above the chat, or their name on any of their messages. It is rebuilt from everything the character remembers plus the first and last 30 messages of the chat. Rebuilds happen after every dream when the account switch on the page is on, or by hand with the Regenerate button. A dream-night rebuild counts against the server's dream cap; a manual rebuild counts as the reader's own requests.

Document import (Memory panel, or the bible page) reads an uploaded backstory, novel excerpt or setting document and proposes Mind Palace entries and short memory facts for review. Nothing enters memory until entries are picked and saved.

The terminal client is 1.6.0. A 1.5.2 client will be refused because the major.minor version no longer matches. Replace the client from this zip, or download it again from the web app.

Before you update, note these changes:
- The Story Bible is stored per chat as bible.json beside memory.md, so it travels with branches and backups that copy the chat folder.
- Rebuild after dreams is off by default; turn it on with the switch on the bible page. It applies the next time that character dreams.
- A character with dreams off and bible rebuild on still has the Regenerate button available at any time.
- Document import reads text, Markdown, Word, PDF and picture files up to 10 MB, like the existing character import. The extraction is one counted request for the account.
- Off-screen life writes one or two short moments a day for a character, and sometimes a twist card. The newest moments join the prompt near the end. Only characters have it; groups and novels do not.
- Author's notes are optional, kept in author_note.md beside a character card, and limited to 4,000 characters.
- Check-ins and dreams can run every 1, 2, 3 or 7 days per character. The server's dream interval still acts as a floor.
- Settings now has a Memory panel for the memory bank, pinned facts, retention, Mind Palace and dreams. Quench long chats moved to Chat history.
- The Relationship card now holds mood as well as affection and trust.
- Reasoning levels appear beside thinking: free and lite get low, standard gets low or medium (DeepSeek low), and pro gets low, medium or high.
- An animated GIF, WebP or APNG background can be up to 100 MB and is stored as uploaded. Still pictures stay at 10 MB, and videos at 50 MB.
- Character creators set trust and affection speed with sliders from 1.00 to 6.00 in steps of 0.01. An existing character auto-saves as the slider moves; a new character keeps the values until Create. Users see only the category and the relationship type, never the number.
- The default trust speed is 3.00 and the default affection speed is 2.00, so a character with no saved file reads Open and Fond, which is Easy company.
- The relationship type for Cautious and Devoted is Tsundere, and Heart of gold with Fond is Heart of gold. The type now appears as the first tag on a character card, and the home page can filter by type, trust category and affection category.
- This beta zip carries no tests folder. Any tests already on the server are left in place and are not updated.

1. Stop the web app.

2. Back up before you update. Make an encrypted backup from the admin page, or copy data/ and your character folders by hand. This zip does not contain them.

3. Extract this zip into the existing project folder, overwriting the files. Do not extract into a new folder.

   The zip leaves alone: .env, data/, every character folder, and the files you keep beside them.

4. Data: nothing new is created on first start; the tables added by 1.6.0-beta-1 are already there for installs that ran an earlier 1.6.0 beta, and fresh installs create them as before. Nothing else in data/ is rewritten.

5. Start the web app again and sign in. Open a chat, click the character's icon or name, and check the bible page; then try Regenerate. Check Memory for the Build from document button, and the dream panel behind it if dreams are on for the character.

6. Run the terminal client from this zip. If an old client is still installed, replace it with client/miso_remote.py.

7. Report anything that breaks against the 1.6.0 release notes in CHANGELOG.md.
