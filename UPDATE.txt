Miso Chat 1.5.0 update

This update brings the server to 1.5.0 from 1.4.1. It adds worlds for stories, novels, narrative tension, a second reading look called Soft Shadows, clipping and quenching that keep long chats cheaper to run, and sign-in hardening for internet-facing use. The endpoints and the data layout are the same as 1.4.1, so chats, characters, accounts and the switches from 1.4.1 carry over.

Everyone is signed out once after the update, because the login cookie has a new name. Sign in again as usual.

The terminal client is now 1.5.0, and the server accepts clients with the same major.minor version. A 1.4.1 client is refused, so download the 1.5.0 client from the web app, or from the release page on GitHub.

1. Stop the web app.

2. Back up before you update. Make an encrypted backup from the admin page, or copy data/ and your character folders by hand. This zip does not contain them.

3. Extract this zip into the existing project folder, overwriting the files. Do not extract into a new folder.

   The zip leaves alone: .env, data/, every character folder, and the files you keep beside them.

4. No new packages are needed. requirements.txt is unchanged. The update adds new modules (worlds, novels, tensions and passwords), new stylesheets and two new font families, all inside the folders the zip brings.

5. Data: no migration step is needed. Each account's worlds and novels are created on first use. The sign-in throttle tables gain one column at first start, added automatically. Nothing in data/ is rewritten.

6. A new install creates the admin account with a random one-time password, printed once in the server log. Sign in with it and change it. An existing install keeps its admin account and password unchanged; change the password if it is still a default one.

7. Settings you may want to look at:
   - Appearance, Theme: Moonlit (the new default), Soft Shadows, Spore (1.5.0) or Hyacinth (1.4.1).
   - Chat history: Clip older messages, on by default. Turn it off to send older messages in full.
   - Chat history: the rolling window. It is at least the size you set, and up to nine messages more.
   - Account: Quench long chats. Off for solo chats until you switch it on. Group chats are quenched unless you switch it off here.
   - Worlds: write a world for a chat or novel. Each entry shows its own token count, and a save over a limit is refused with a message.

8. Group chats: each member's reply is prompted differently in this release, so check a few replies after the update. A group now allows two extra replies a turn after the director's picks, down from four.

9. Optional: install chafa to draw character pictures in the terminal client. The README has the steps.
